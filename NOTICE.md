# Notices and inspiration

**KINETIQ Machine Simulation Skills** is an independently authored collection by **Harsh Singh (@voyager67)**.

The collection is conceptually inspired by the public [`elvarofficial/teardown`](https://github.com/elvarofficial/teardown) project, a Claude Code skill for building interactive 3D machine simulators. That reference project is distributed under the MIT License. Its broad workflow ideas—model-driven motion, subsystem inspection, cutaways, guided tours, and repeatable visual review—informed the direction of KINETIQ.

KINETIQ's skill text, templates, documentation, installer, validator, and interactive catalogue are independently written. No upstream Teardown source files, skill prose, runtime code, machine examples, recorded audio, images, or other assets are included in this repository.
